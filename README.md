# 小学语文古诗词全表（统编版）

> **Elementary Chinese Poems** · 小学统编版古诗词篇目速查工具

一份纯静态、免费开放的「小学语文（统编版）古诗词篇目」速查工具，收录人民教育出版社统编（部编）语文教材 1—6 年级全部必背古诗词，共 **112 首**。

项目以公益科普为宗旨，面向家长、教师和学生，提供按册次、体裁、朝代、作者快速检索的便捷入口。无广告、无收费、无用户追踪。

## 项目定位

- **免费开放**：纯前端静态页面，单个 HTML 文件即可运行，无需服务器与数据库。
- **数据透明**：全部篇目与统计数据内联在源码中，任何人都可直接查阅、核对、复用。
- **尊重版权**：仅收录篇目名、作者、朝代、体裁等客观信息，用于学习与教学参考；不转载教材正文原文。
- **公益科普**：与人民教育出版社无任何隶属或合作关系，不用于任何商业用途。

## 功能特性

- **全表浏览**：112 首古诗词按「一年级上册」至「六年级下册」分册展示。
- **全文检索**：支持按诗名、作者、册次、朝代即时搜索。
- **体裁筛选**：五言 / 七言 / 词 / 乐府 / 民歌 / 四言，一键过滤。
- **统计概览**：总计、体裁分布、朝代分布、高频诗人一目了然。
- **响应式设计**：桌面与移动端均可正常浏览，支持打印。
- **零依赖**：HTML + CSS + 原生 JavaScript，无需构建、无需联网、无第三方库。

## 数据来源与归类说明

- **篇目来源**：人民教育出版社「微言教育」官方公布的统编（部编）语文教材古诗词篇目。
- **体裁归类**：词、乐府、民歌、四言不归入五言 / 七言，单列一类。
- **朝代标注**：教材标注「佚名」的作品朝代以「—」表示；「近现代」指毛泽东词作。

## 快速开始

### 方式一：直接打开

下载仓库中的 `index.html`，用任意现代浏览器（Chrome / Edge / Safari / Firefox）双击打开即可，无需任何配置。

### 方式二：部署为 GitHub Pages

1. 在仓库 **Settings → Pages** 中选择部署分支（如 `main`）与根目录。
2. 保存后访问生成的 `https://<用户名>.github.io/<仓库名>/` 链接。

## 技术说明

- 纯 HTML + CSS + 原生 JavaScript，无任何第三方依赖。
- 篇目数据以内联 JSON 形式保存在页面脚本的 `RECORDS` 数组中，便于二次开发与扩展。
- 增删篇目只需编辑 `RECORDS` 数组中的条目，页面渲染与统计会自动更新。
